Stock Skin Build

Result for Stock Skin Build
Steps
Expected Result

The player wears the stock look, a pink top with black leather. No outfit shows, and the game does not crash.

Close the game before each install. Each case names the build folder it installs from. The temporary two-star wanted level in MAIN is still present, so the police chase the player from the start.

The outfits come from skins/All Skins.jpg. The striped utility outfit is gold stripes with olive trousers and knee pads. The scarred leather outfit is orange scarred leather with ripped black trousers. The stock look is a pink top with black leather.

For each case, capture one screenshot of the player character and note whether the texture was the outfit, stock, white, or missing. If the game crashes, keep the full exception report and the last lines of scrlog.log in the game folder.
