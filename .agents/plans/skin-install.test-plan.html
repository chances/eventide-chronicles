Scope and Setup

  • Target gta-vc.exe v1.0. Run every command from the repository root.
  • Close the game before each install:skins command. It writes to the game's archive. Each case names the build folder it installs from.
  • The outfits come from skins/All Skins.jpg. The striped utility outfit is gold stripes with olive trousers and knee pads. The scarred leather outfit is orange scarred leather with ripped black trousers. The stock look is a pink top with black leather.
  • The temporary two-star wanted level in MAIN is still present, so the police chase the player from the start.

Striped Utility at New Game

Steps
  1. Close the game. Run deno task install:skins --from dist/builds/striped_utility.
  2. Run deno task run and begin a new game.
  3. When the fade-in ends, look at the player character, and turn the camera to see the jacket and the trousers.
Expected

The player wears the gold-striped jacket and the olive trousers with knee pads of the striped utility outfit. The model is not white, not untextured, and not the stock pink top. The game does not crash.

Striped Utility After a Skin Thread Re-dress

Steps
  1. Continue from GM-01 in the same game session.
  2. Go to the first Skin location, at -108.3, -974.4, 9.4, and stay within 5 units.
  3. Watch the screen fade out and fade in, then look at the player character again.
Expected

The player still wears the striped utility outfit after the fade. The stock pink top does not come back, and the game does not crash.

Striped Utility at the Other Skin Locations

Steps
  1. Continue from GM-02 in the same game session.
  2. Go to each of these places in turn, and stay within 5 units for the fade: 508.9, 506.8, 10.3, -822.6, 1149.8, 12.4, 398.8, -469.7, 10.7, -872.2, -683.4, 11.2, and -885.5, -471.0, 13.1.
  3. After each fade, look at the player character.
Expected

The player wears the striped utility outfit after every fade. Note any place where the stock look comes back or the game crashes.

Scarred Leather Build

Steps
  1. Close the game. Run deno task install:skins --from dist/builds/scarred_leather.
  2. Run deno task run and begin a new game.
  3. Look at the player character, and turn the camera to see the jacket and the trousers.
Expected

The player wears the orange scarred leather jacket and the ripped black trousers of the scarred leather outfit. The striped utility outfit is gone, and the game does not crash.

Stock Skin Build

Steps
  1. Close the game. Run deno task install:skins --from dist/builds/stock.
  2. Run deno task run and begin a new game.
  3. Look at the player character, and turn the camera to see the jacket and the trousers.
Expected

The player wears the stock look, a pink top with black leather. No outfit shows, and the game does not crash.

Evidence and Pass Criteria

  • For each case, capture one screenshot of the player character and note whether the texture was the outfit, stock, white, or missing.
  • If the game crashes, keep the full exception report and the last lines of scrlog.log in the game folder.
